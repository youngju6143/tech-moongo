## **1. 연구 배경 (Background)**

최근 개발자들은 학습 및 지식 정리를 위해 기술 블로그를 적극적으로 활용하고 있다. 그러나 기존 블로그 플랫폼은 글을 시간순 리스트 형태로 제공하는 구조에 머물러 있어, 다음과 같은 한계가 존재한다.

- 장기적인 성장 흐름을 직관적으로 파악하기 어려움
- 특정 기술 분야에 대한 학습 편중 여부 확인이 어려움
- 글의 분량, 난이도, 주제 간 관계 등 복합적인 정보 파악의 어려움

이러한 문제는 데이터가 존재함에도 불구하고, **적절한 시각화 방식이 부재**하기 때문에 발생한다.

## **2. 연구 목적 (Objective)**

본 연구는 기술 블로그 데이터를 3차원 가상 공간으로 변환하여 단순한 정보 나열을 넘어, **개발자의 학습 패턴과 성장 흐름에 대한 통찰을 제공하는 시각화 시스템**을 구현하는 것을 목표로 한다.

구체적인 목적은 다음과 같다.

- 블로그 메타데이터를 활용하여 **지식 구조를 공간적으로 표현**
- 시각화를 통해 기존에는 인지하기 어려웠던 **학습 편향, 성장 추이, 활동 밀도** 등의 정보 도출
- 개발자에게 **지속적인 글 작성 동기 및 성취감 제공**
- 포트폴리오로 활용 가능한 **인터랙티브 3D 프로필 시스템 제공**

---

## **3. 연구 문제 정의 (Problem Statement)**

기존 기술 블로그 서비스는 다음과 같은 한계를 가진다.

1. **정적 리스트 기반 UI**
   - 시간순 정렬 외의 의미 있는 구조 제공 부족
2. **메타데이터 활용 부족**
   - 작성일, 카테고리, 분량 등의 정보가 존재하지만 통합적으로 해석되지 않음
3. **자기 피드백 어려움**
   - 개발자가 자신의 학습 방향성을 점검하기 어려움

따라서 본 연구는 다음 질문을 해결하고자 한다.

> “기술 블로그 데이터를 3D 공간으로 재구성했을 때, 개발자의 학습 패턴과 성장 흐름에 대한 새로운 인사이트를 제공할 수 있는가?”

## **4. 시스템 개요 (System Overview)**

본 시스템은 사용자의 기술 블로그(Notion DB) 데이터를 수집하여, 이를 3D 가상 서재 형태로 변환 및 시각화하는 웹 기반 서비스이다. 별도의 사용자 로그인 절차 없이, 대상 Notion 데이터베이스 ID를 기준으로 동작하며 Notion 토큰은 백엔드에만 보관하여 클라이언트에 노출하지 않는다.

### **전체 흐름**

1. 백엔드 프록시를 통한 Notion 데이터베이스 조회 (`status = Public` 게시글 대상)
2. 각 페이지 본문·메타데이터 수집 및 정제 (글자 수, 코드/키워드, 블록 타입 분포)
3. 정량 점수 산출 및 TF-IDF 유사도 분석
4. 점수 → 3D 디자인 요소 매핑 및 서가 배치
5. 3D 서재 렌더링 및 사용자 인터랙션 제공

## **5. 데이터 기반 시각화 설계 (Visualization Design)**

### **5.1 Mapping Rule 정의**

블로그 데이터를 단순히 표현하는 것이 아니라, **의미 있는 정보 해석이 가능하도록 매핑 규칙을 설계**한다.

| **데이터 요소**       | **3D 표현 방식**          | **기대 인사이트**          |
| --------------------- | ------------------------- | -------------------------- |
| 카테고리              | 책 색상 / 군집 배치       | 기술 스택 편향             |
| 정보량(글 분량)       | 책 두께                   | 학습 깊이                  |
| 전문성(코드·키워드)   | 표지 패턴/질감            | 기술적 깊이                |
| 활동성(최근성·연속성) | 책 발광(emissive)         | 최근 관심 분야 / 활동 밀도 |
| 작성일                | 군집 내 정렬 순서         | 시간에 따른 성장 흐름      |
| 제목 길이             | 책 높이 (보조 시각 요소)  | 시각적 다양성              |

### **5.2 인사이트 도출 기능 (핵심 차별화)**

단순 시각화를 넘어서 다음과 같은 **해석 가능한 정보**를 제공한다.

**1) 학습 편향 분석**

- 카테고리별 비중을 레이더 차트로 시각화 (최근 3개월 기준)
  → 특정 기술 분야에 편중된 학습 패턴 확인 가능

**2) 활동 흐름 시각화**

- GitHub 잔디 스타일의 연간 활동 히트맵
  → 작성 빈도와 공백 기간을 직관적으로 파악

**3) 학습 깊이 분석**

- 두꺼운 책 vs 얇은 책, 발광 강도 분포
  → 얕은 학습 vs 깊이 있는 학습, 최신 활동 비교

**4) 주제 유사도 분석**

- TF-IDF 코사인 유사도 기반으로 비슷한 주제의 글을 군집화
  → 글 호버 시 상위 키워드와 '비슷한 글' 목록 제시

## **6. 시스템 아키텍처 (Architecture)**

본 시스템은 프론트엔드(`apps/web`)와 백엔드(`apps/api`)를 분리한 모노레포 구조이다.

### **6.1 Data Layer (Backend · FastAPI)**

- Notion API 프록시 기반 데이터 수집 (토큰은 서버 환경변수로만 보관)
- 본문 파싱 및 블록 타입 분포 추출
- kiwipiepy 형태소 분석 + TTA 용어사전 기반 기술 키워드 매칭
- scikit-learn 기반 TF-IDF 벡터화 및 코사인 유사도/클러스터링

### **6.2 Logic Layer (Frontend · 점수/배치)**

- 데이터 → 정량 점수(정보량·전문성·활동성·독창성) 산출
- 점수 → 3D 디자인 요소 매핑 로직
- 공간 배치 알고리즘 (카테고리 군집화, 서가/책장 정렬)

### **6.3 Presentation Layer (Frontend · React + Three.js)**

- Three.js 기반 3D 서재 렌더링
- 카메라 이동 및 사용자 인터랙션 처리
- 책 호버 시 툴팁(키워드·유사 글), 클릭 시 Notion 원문 연결

## **7. 주요 기능 (Key Features)**

### **7.1 3D 가상 서재 탐색**

- 자유 시점 이동
- 책 호버 시 상세 정보(제목·키워드·비슷한 글) 툴팁 표시
- 책 클릭 시 해당 Notion 원문 페이지로 이동

### **7.2 인사이트 시각화 오버레이**

- 카테고리 분포 레이더 차트 (학습 편향)
- 활동 히트맵 (연도·테마 선택 가능)

### **7.3 공유 기능**

- 개인 3D 서재 URL 생성 (`/share/:dbId`, 읽기 전용)
- 포트폴리오 연동 가능

## **8. 기대 효과 (Expected Outcomes)**

- 개발자의 학습 데이터를 **직관적으로 해석 가능**
- 블로그 작성에 대한 **지속적인 동기 부여**
- 기존 포트폴리오와 차별화된 **인터랙티브 결과물 제공**
- **데이터 시각화 + 3D 그래픽스 결합 사례 제시**
